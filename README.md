# Agricultural Yield Predictor

A full-stack machine learning web app that predicts crop yield (Tonnes/Hectare) from weather, soil, and farm management inputs — built with **scikit-learn**, **Flask**, and **vanilla JS**.

---

## Live Pages

| Page | URL |
|------|-----|
| Prediction UI | `http://localhost:5000/` |
| Analytics Dashboard | `http://localhost:5000/dashboard` |

## Quick Start

### 1. Clone the repo
```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Train the model  *(first time only)*
```bash
python agri_yield_predictor/train_model.py
```
This generates `agri_yield_predictor/models/best_model.pkl` and `label_encoders.pkl`.

### 4. Start the server
```bash
python app.py
```

### 5. Open in browser
-Prediction UI: http://127.0.0.1:5000/
-Dashboard: http://127.0.0.1:5000/dashboard

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/health` | Health check |
| GET | `/api/meta` | Feature list & unique values |
| POST | `/api/predict` | Single yield prediction |
| POST | `/api/batch_predict` | Batch predictions |
| GET | `/api/stats` | Dataset statistics |
| GET | `/api/model_metrics` | RMSE / MAE / R² for all models |
| GET | `/api/crop_analysis` | Per-crop yield stats |
| GET | `/api/season_analysis` | Per-season yield stats |
| GET | `/api/state_analysis` | Per-state yield stats |
